An offline, open-source guide and tracker for all 55 Grand Theft Auto VI PlayStation 5 trophies: the official list with a cited guide for each trophy, a roadmap to the platinum, missable flags built from the official descriptions, a checklist whose progress is saved in the browser with export and import, filters by kind, and a spoiler setting that hides story trophies until they are earned. Plain static files: no build step, no network, no account.

## Run it

```sh
node serve.ts
```

then open http://localhost:8080 — or serve the `app/` folder with any static file server and open `app/index.html`.
